A subsequent native build could exhaust S:, fail partway, and leave incomplete incremental artifacts. **Action:** remove only the regenerable `debug` directory after verifying no Cargo/Rust compile or Snowy executable is active; keep `release`, `.cache/cargo`, `node_modules`, project files and Git history. 3. **Two tracked files are unreadable.** Both `README.md` and `.github/workflows/android-apk.yml` fail with `Permission denied` through Git, RDC and Python, although metadata can be inspected. Git cannot reliably diff these files or prove a clean tree. **Action:** investigate attributes/handles and restore readable access without overwriting existing bytes; otherwise report the blocker and exclude these files from commits.

4. **Overlay-first-frame safety regression in working tree.** Committed Rust code intentionally leaves an overlay hidden until `src/overlay.ts` successfully draws a frame and calls `ownWindow.show()`. Uncommitted `src-tauri/src/lib.rs` restores eager `w.show()`, violating that ordering; on a renderer failure, an overlay can remain visible with no rendered snow. **Action:** preserve capability permissions for `core:window:allow-show` and restore first-frame-only showing, with a regression contract test.

Existing draft PR #1 targets `main` from `feat/cross-platform-snow-alpha`, which diverged from the latest feature branch (16 ahead, three behind). Merging PR #1 as if current risks shipping the wrong branch. **Action:** compare and reconcile unique changes; prepare a new current-feature PR, preserving existing PR until reviewed; do not merge `main` without the explicit real-hardware acceptance required by `AGENTS.md`.

6. **Feature branch lacks an upstream in local Git.** `git rev-parse @{upstream}` fails, so `git pull` on this branch is ambiguous. **Action:** set its upstream to `origin/feat/cross-platform-snow-physics-alpha` after safe checks; avoid non-fast-forward pushes.
